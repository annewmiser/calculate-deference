# โปรแกรมคำนวณส่วนต่างแพ็กเกจ

เปิด `index.html` ในเบราว์เซอร์ได้โดยตรง ไม่ต้องติดตั้ง dependencies

## โหมดรายเดือน

กรอกราคาแพ็กเกจเดิมและใหม่ต่อเดือน **ก่อน VAT** พร้อมจำนวนวันที่เหลือในรอบบิล
ใช้ฐานสัญญาคงที่ **30 วัน** และ VAT **7%** ตามกติกาของโปรแกรม

```text
มูลค่าแพ็กเกจเดิม = ราคาเดิม / 30 × วันที่เหลือ
มูลค่าแพ็กเกจใหม่ = ราคาใหม่ / 30 × วันที่เหลือ
ส่วนต่างก่อน VAT = มูลค่าแพ็กเกจใหม่ − มูลค่าแพ็กเกจเดิม
VAT = ส่วนต่างก่อน VAT × 0.07
ส่วนต่างสุทธิ = ส่วนต่างก่อน VAT + VAT
```

ตัวอย่าง: รอบบิล 15/09/2026–15/10/2026 เปลี่ยนจาก 700 เป็น 1,000 บาทต่อเดือน
เมื่อเหลือ 15 วัน: มูลค่าเดิม 350 บาท, มูลค่าใหม่ 500 บาท, ส่วนต่าง 150 บาท,
VAT 10.50 บาท, **สุทธิ 160.50 บาท**

- ผู้ใช้กรอกวันที่เหลือเองเป็นจำนวนเต็ม 0–30 วัน ไม่มีการคำนวณจากวันที่ปัจจุบัน
- ราคาต้องเป็นตัวเลขตั้งแต่ 0 ขึ้นไป รองรับแพ็กเกจฟรี
- คำนวณด้วยราคาต่อวันเต็มความละเอียด และแสดงผลเป็นทศนิยม 2 ตำแหน่ง
- หากราคาใหม่ต่ำกว่าเดิม ผลลัพธ์ติดลบเป็นส่วนต่างเครดิตตามสูตร

## โหมดการคำนวณส่วนต่าง package เดียว

แทนที่โหมดราคา Contract เดิม โดยรับราคาแพ็กเกจต่อเดือนและจำนวนวันที่เหลือ (0–30 วัน)
ใช้ฟังก์ชัน `calculate_difference_price_oldder_product` ตามสูตร:

```text
ราคาต่อวัน = ราคาแพ็กเกจ / 30
ส่วนต่างตามวันที่เหลือ = ราคาต่อวัน × วันที่เหลือ
ส่วนต่างตามวันที่เหลือ (รวม VAT) = ส่วนต่างตามวันที่เหลือ × 1.07
```

ตัวอย่าง: ราคา 700 บาท เหลือ 15 วัน แสดงราคาต่อวัน 23.33 บาท ส่วนต่างก่อน VAT **350.00 บาท**
และส่วนต่างรวม VAT 7% **374.50 บาท**
คำนวณราคาต่อวัน ส่วนต่าง และ VAT ด้วยค่าเต็มความละเอียดก่อนแสดงผลเป็นทศนิยม 2 ตำแหน่ง
